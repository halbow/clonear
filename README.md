# Clonear

A tiny, Linear-style kanban board whose **backend is just folders and files**.
No database, no npm, no server: one HTML file, `dist/clonear.html`.

## Usage

Use it either way:

- **As a single HTML file:** copy `dist/clonear.html` into any repo and open it in
  Chrome, Edge or Arc.
- **Online:** go to <https://kanban.lofiso.app>.

Then click **Open folder** and pick the folder that holds your tickets.
